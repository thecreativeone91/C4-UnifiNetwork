UniFi PoE Port (Open Source)

Controls PoE power on one port of a UniFi switch or gateway: on, off, toggle and power cycle, with live PoE draw and link state. Use it to reboot a camera, access point or other PoE device. It works through the UniFi Network driver, which must be in the project and connected.

Setup

  1. Connections → Control: bind this driver's UniFi Network connection to the UniFi Network driver.
  2. Pick the UniFi Device. The list fills in once the UniFi Network driver is connected.
  3. Pick the PoE Port. Status reads OK when the driver is tracking it.
  4. Optional: bind Power Relay to a Control4 relay-type driver to get Navigator/keypad control, and Power State Contact to a contact driver to show the power state.

Properties

PropertyNotes
UniFi Device / PoE PortWhat this driver controls. Names come from UniFi; commas are dropped from list entries.
Power Cycle MethodSwitch Power Cycle asks the switch to cycle the port (official API POWER_CYCLE). Off Then On turns PoE off, waits, and turns it back on through the port settings.
Power Cycle Off Time (seconds)How long power stays off during an Off Then On power cycle (default 10).
Debug ModeExtra Lua output.

Read-only: Driver Version, Status, Port Name, PoE Mode, PoE Delivering Power, Link, Uplink Port, Device Status, Power State, Power Draw, Last Error.

Programming

  • Commands: Power On, Power Off, Toggle Power, Power Cycle
  • Events: Power Turned On, Power Turned Off (also when changed in the UniFi app), Power Cycle Started, Power Cycle Complete, Command Failed, Device Online, Device Offline
  • Variables: POWER_STATE (bool), POWER_WATTS, DEVICE_ONLINE (bool) – usable in conditionals
  • Actions: Power On, Power Off, Toggle Power, Power Cycle, Refresh

Connections

ConnectionBehavior
UniFi Network (control, consumer)Link to the master driver.
Power Relay (RELAY)CLOSE = power on, OPEN = power off, TOGGLE = toggle, TRIGGER = power cycle. Reports CLOSED while powered.
Power State Contact (CONTACT_SENSOR)Closed while powered, open while off.

Notes

  • Only PoE-capable ports are listed. A switch's uplink port is marked (uplink); with Protect Uplink Ports on (UniFi Network driver) it cannot be turned off or cycled.
  • Power On restores the port's previous PoE mode (802.3 auto, passive 24V or passthrough).
  • A switch power cycle only works while the port is delivering PoE.

Never turn off a port that powers the UniFi console, the Control4 controller or a switch between them; you would lose the connection needed to turn it back on.
