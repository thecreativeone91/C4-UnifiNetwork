UniFi Network (Open Source)

Master driver for a UniFi Network console (Cloud Gateway, UDM, UCG, UniFi OS Server, Cloud Key, or the self-hosted Network application). It reads your PDUs and PoE switches from the UniFi Network API and serves two child drivers bound to its UniFi Network connection:

  • UniFi PDU Outlet – one outlet of a UniFi SmartPower PDU, strip or plug: on, off, toggle, power cycle.
  • UniFi PoE Port – PoE power on one switch or gateway port: on, off, toggle, power cycle.

On the UniFi console

  1. API key (UniFi OS consoles and UniFi OS Server): UniFi Network → Settings → Control Plane → Integrations (called API Keys on some versions) → create a key and copy it.
  2. Local account (needed for the self-hosted Network application, and on consoles whose classic API refuses the API key – the Status property tells you): create a local-only admin with Network admin rights (Site Admin or Full Management), remote access off, no MFA.
  3. Give the console a fixed address.

Composer setup

  1. Add this driver. Set Controller Address and either API Key, Username/Password, or both.
  2. Run the Test Connection action. Status should read Connected and the device counts should fill in.
  3. Add one UniFi PDU Outlet or UniFi PoE Port driver per outlet or port you want to control.
  4. Connections → Control: bind each child's UniFi Network connection to this driver's UniFi Network connection.
  5. In each child, choose the UniFi Device, then the Outlet or PoE Port.

How it talks to UniFi

TaskAPI
Network version, site, device idsOfficial Network API (/proxy/network/integration/v1, API key)
PoE port power cycle (switch side)Official API POWER_CYCLE port action; falls back to the classic cmd/devmgr power-cycle
Port and outlet state, PoE on/off, outlet on/offClassic controller API (stat/device, rest/device port_overrides / outlet_overrides). The official API has no on/off for these yet.

Classic requests use the local account when a Username is set, otherwise the API key. Every on/off write re-reads the device first and writes back the complete override array, so other ports and outlets keep their profiles, names and states. Writes are sent one at a time.

Programming

  • Events: Connected, Connection Lost
  • Command: Refresh Devices
  • Actions: Test Connection, Refresh Devices, Log Device List (writes every PDU outlet and PoE port to the Lua output)

Troubleshooting

StatusFix
the console rejected the API key on the classic APIAdd a local Username and Password.
login rejectedUse a local-only account without MFA; check the password.
login rate-limitedWait a few minutes; the console throttles repeated failed logins.
cannot reach controllerCheck address and port; the controller must reach the console over HTTPS.
site not foundSet Site to the internal site name (see the URL in the UniFi web UI).

Changing PoE or an outlet makes the console re-provision that device; the new state shows within a few seconds. Turning PoE off on a port that feeds this console, the Control4 controller or a switch upstream of them will cut your own control path – leave those ports out.
